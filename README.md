【Temple of the Three Sprites】
【三元精灵神殿】


一、世界的初始设定
1. 三个生命体：
🔵 Circle — 蓝色圆形 · 祭司
   The Priest
初始信念：他要不断获得神谕，神谕会增加他们的知识程度。
能力/分工：1️⃣举办仪式；2️⃣翻译语义碎片；3️⃣记录

⚠️（没有这个emoji qwq） Triangle — 黄色三角形 · 骑士
   The Knight
初始信念：所有人都需要食物，只有他有能力获取食物。
分工：1️⃣寻找食物；2️⃣寻找砖块、砌砖块盖金字塔神殿

🟥 Square — 红色正方形 · 建筑师
   The Architect
分工：1️⃣建造神殿；2️⃣寻找掉落的语义碎片，比如字母/数字/单词，拿到祭司那里，祭司会告诉它什么意思、怎么用；3️⃣记录，比如神殿建造进度


2. 世界环境：
世界背景是纯白的，三个小精灵知道这个世界中只有他们三个生命。他们没有怀疑过自己从哪来，但是知道自己为什么在这、要做什么。
知识来自祭司，祭司的知识来自接受神圣的启示（当然我们知道是世界之外输送给他的，aka开发者）。举办仪式就可以获得来自世界之外输送进的新信息、新能力。
骑士要保证大家有食物（虽然其实他们并不会饿死，目前暂不引入生命值系统）。但是骑士不识字（至少开始的时候），不会捡拾语义碎片。

4. 世界任务：
· 举办仪式，获得神谕
· 找食物
· 建神殿
· 记录（有点像结绳记事，但是使用已有的语义碎片）

5.世界资源
· Food
· Bricks
· Semantic Fragments

6. 神谕系统 Oracle System
它有权访问世界之外的信息，但三个生命体都不能直接访问它。
只有祭司能够发起仪式。
仪式成功后，神谕可以携带两种内容：
   Knowledge - 增加事实性知识。
   Capability - 解锁一种认知操作，比如记忆功能。


二、目标
开发者（本人，此世界的Creator）不需要控制任何生命体。主要操作是运行、暂停、加速、查看记录、重启实验，以及在需要时从世界之外配置神谕。

三、后期美工
将使用简单的像素绘图，比如森林/砖块。
